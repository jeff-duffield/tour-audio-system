Step 1: Connect to Internet

ℹ️ The internet uplink is automatically disconnected whenever a guide starts broadcasting (a background WiFi reconnect scan was found to cause periodic audio glitches). It stays disconnected afterward — use "Connect" here anytime you need internet back (e.g. to run an update).
Checking connection…
iPhone:
  1. Settings → Personal Hotspot → turn on "Allow Others to Join"
  2. Note the Wi-Fi password shown on that screen
  3. Scan networks above; your iPhone name should appear
Android:
  1. Settings → Network & Internet → Hotspot & tethering → Wi-Fi hotspot → turn on
  2. Note the hotspot name and password
  3. Scan networks above to find it
